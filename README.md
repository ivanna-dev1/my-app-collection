# My App Collection

My projects hub — a collection of educational apps I created while learning JavaScript, React, Tailwind CSS, and Next.js.

The home page shows all projects as cards. Hover a card to see a short description, click it to open the project.

## Projects

**React (Next.js pages)**

- Tic-Tac-Toe
- Currency Converter
- Todo App
- Shopping List
- Event RSVP Form
- Superhero Application Form
- OTP Generator
- Fruits Search
- Color Picker
- Mood Board
- Pricing Component
- CTA Component

**HTML / CSS / JavaScript / TypeScript**

- Shape Manager (TypeScript)
- Calculator (my first JavaScript project)
- Dior Landing Page
- iPhone Landing Page
- 3D Game Promotional Site

## Technologies

Next.js (App Router), React, JavaScript, TypeScript, Tailwind CSS, CSS3, HTML5.

## Run locally

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).
